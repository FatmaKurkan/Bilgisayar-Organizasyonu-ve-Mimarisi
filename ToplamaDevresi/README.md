4 Bitlik Toplama Devresi
Ödevin Amacı
En az 4 bitlik toplama işlemi yapan bir devrenin tasarlanması ve test edilmesi.

Tasarım
İki adet 4 bitlik ikili sayı toplanır. Sonuç, elde biti de gösterebilmek için 5 bit olarak elde edilir.

Dosyalar
design.sv: Toplama devresinin tasarım kodu.
testbench.sv: Toplama devresini test etmek için kullanılan kod.
Test İşlemleri
3 + 2 = 5
7 + 4 = 11
15 + 1 = 16
8 + 8 = 16
0 + 0 = 0
